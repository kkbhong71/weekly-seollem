# 일주일의 설렘 🍀

> 8가지 렌즈로 고른 세상에 하나뿐인 번호, 부담 없이 설레는 일주일

**바로 쓰기:** https://kkbhong71.github.io/weekly-seollem/

브라우저만 있으면 되는 단일 HTML 웹앱입니다. 설치, 회원가입, 서버가 필요 없고, 기록은 각자의 브라우저에만 저장됩니다.

## 일주일 흐름

| 요일 | 화면 | 하는 일 |
|---|---|---|
| 월 | 번호 탄생 | 밤하늘을 손끝으로 휘저어 나만의 난수 씨앗 만들기 → 8가지 렌즈가 번호 생성 |
| 화~금 | 드림 위크 | 확률 이야기, 이번 주 번호의 성격, 드림 캡슐(큰 꿈 + 1,000원짜리 작은 꿈) 봉인 |
| 토 | 운명의 밤 | 당첨번호 입력 → 공이 하나씩 떨어지며 모든 세트와 실시간 대조 |
| 일 | 쉼표 | 작은 꿈 미션, 설렘 적금, 렌즈 리그(백테스트·실전 성적) |

## 8가지 렌즈

| 렌즈 | 방법 |
|---|---|
| 🛡️ 회피 | 대중이 덜 고르는 조합 하위 3% 안에서 무작위 → 당첨 시 나눠 가질 가능성 ↓ |
| 💛 선호 | 직접 고른 번호 중심, 빈자리는 비인기 번호로 채움 |
| 📈 패턴 | 빈도·최근 50회 빈도·미출현 간격·모멘텀·마르코프 5종 점수 앙상블 |
| ⚖️ 균형 | 합계·홀짝·고저·AC값·연번·끝수·번호대·최근 과열 8중 필터 |
| 🔥 핫·콜드 | 최근 뜨거운 번호 3 + 오래 쉰 번호 2 + 나머지 1 |
| 🤝 궁합수 | 역대 동반 출현 쌍 네트워크 |
| 🔗 마르코프 | 지난 회차 다음에 자주 나온 번호(전이 확률) |
| 🧬 종합 진화 | 위 기준을 모두 적합도로 묶은 유전 알고리즘 |

모든 세트에 같은 잣대(대중 선호도 · 당첨 시 예상 몫 · 패턴 점수 · 균형 검사)를 붙여 비교할 수 있습니다.

## 정직한 자기 검증

- **렌즈 리그 백테스트:** 과거 각 회차를 그 이전 데이터만으로 예측(walk-forward)하고, 완전 무작위 대조군과 비교합니다. 회차 단위 표본과 Holm-Bonferroni 보정으로 "우연히 1등한 렌즈" 착시를 막습니다.
- **공유해도 번호가 겹치지 않게:** 씨앗은 사용자마다 다르고, 회피·종합 진화 렌즈도 상위 후보 중에서 무작위로 고릅니다(20명 × 3세트 시뮬레이션에서 60세트 모두 서로 다름).
- **예산 가드:** 주간 예산을 넘는 구매 표시는 막힙니다.

## 데이터 갱신 (매주 토요일 추첨 후)

1. 최신 회차를 추가한 CSV를 **`new_회차.csv`** 이름으로 저장합니다. (예: 1251회 추첨 후 → `new_1251.csv`, 형식: `round,draw date,num1,...,num6`)
2. GitHub 저장소의 `data` 폴더에서 **Add file → Upload files**로 올리고 커밋합니다.
3. 끝. 앱이 날짜로 이번 회차를 계산해 `new_1252 → new_1251 → new_1250 …` 순서로 찾아, 가장 최신 파일을 자동으로 불러옵니다.

- 이전 파일(`new_1250.csv` 등)은 지워도 되고 기록으로 남겨 둬도 됩니다.
- 앱 안의 내장 데이터까지 바꾸려면 `src` 폴더에서 `python3 build.py --data`를 실행하고 `index.html`을 커밋합니다(선택 사항).
- 사용자는 앱 하단 **당첨번호 데이터**에서 CSV를 직접 올릴 수도 있습니다(동행복권 원본 CP949 지원).

## 폴더 구조

```
index.html        배포되는 앱 (빌드 결과물, 단일 파일)
data/new_XXXX.csv 최신 당첨번호 (자동 갱신용, 매주 추가)
src/engine.js     계산 엔진: 확률표, 난수, 분석, 렌즈 8종, 유전 알고리즘, 백테스트
src/src.html      화면 템플릿
src/data.txt      내장 데이터(압축)
src/build.py      빌드 스크립트
```

## 면책
