**바로 쓰기:** https://kkbhong71.github.io/weekly-seollem/

브라우저만 있으면 되는 단일 HTML 웹앱입니다. 설치, 회원가입, 서버가 필요 없고, 기록은 각자의 브라우저에만 저장됩니다.

**함께 쓰는 기능**
- **제외수**: 번호를 두 번 누르면 제외수가 되어 모든 렌즈에서 빠집니다(최대 20개).
- **구매 조합 최적화**: 만든 세트 중 '하나라도 5등 이상' 확률이 가장 높은 조합을 골라 줍니다(새 가상 추첨 4만 회로 검증한 값만 표시).

사주·띠·타로는 번호를 정하는 해석 체계를 지어내야 해서 넣지 않았습니다.

모든 세트에 같은 잣대(대중 선호도 · 당첨 시 예상 몫 · 패턴 점수 · 균형 검사)를 붙여 비교할 수 있습니다.

## 정직한 자기 검증

- **렌즈 리그 백테스트:** 과거 각 회차를 그 이전 데이터만으로 예측(walk-forward)하고, 완전 무작위 대조군과 비교합니다. 회차 단위 표본과 Holm-Bonferroni 보정으로 "우연히 1등한 렌즈" 착시를 막습니다.
- **공유해도 번호가 겹치지 않게:** 씨앗은 사용자마다 다르고, 회피·종합 진화 렌즈도 상위 후보 중에서 무작위로 고릅니다(20명 × 3세트 시뮬레이션에서 60세트 모두 서로 다름).
- **예산 가드:** 주간 예산을 넘는 구매 표시는 막힙니다.

## 쓰기 편하게 (v0.6~v0.8)

- **처음 사용자 안내 6장**: 첫 방문 때 자동으로 열리고, 상단 ❓ 사용법으로 다시 볼 수 있어요.
- **간단 모드**: 기본 화면은 렌즈가 겹치지 않는 **추천 5세트**만 보여 줘요(함께 샀을 때 '하나라도 5등 이상' 확률이 가장 큰 조합). 전체 렌즈는 버튼 하나로 펼쳐져요.
- **실수 방지**: 번호를 다시 만들기 전에 확인하고, 이전 번호는 🗂 보관함에 자동 보관돼요(구매 세트 유지 가능).
- **🧾 용지 마킹 보기**: 판매점 용지와 같은 7칸 배치로 칠할 자리를 보여 줘요.
- **결과 자동 처리**: 저장소에 새 CSV가 올라오면 토요일 당첨번호가 자동으로 채워지고, 결과를 입력하지 않은 지난 회차도 자동 채점돼요.
- **기록 백업·복원**: 백업 코드(또는 파일)로 기기를 바꿔도 기록을 옮길 수 있어요.
- **접근성**: 가+ 큰 글씨, 맞은 공에 ✓ 표시(색만으로 구분하지 않음), 키보드·화면 낭독기 지원, 움직임 줄이기 설정 존중.
- **나눔**: 📤 공유(휴대폰 공유 창), 설렘 카드 공유, 📲 홈 화면에 설치(PWA, 오프라인에서도 열림), 📅 매주 토요일 캘린더 알림(18:00 마감 2시간 전 + 20:35).
- **건강하게**: 이번 달 누적 금액, 3주 연속 예산을 꽉 채우면 쉬어 가기 권유, 데이터가 늦으면 알림.
- **개인정보**: 번호·꿈·기록은 기기 안에만 저장. 외부 연결은 공개 난수(drand)·지진 데이터(USGS)·당첨번호 파일을 받아 올 때뿐이에요.

## 데이터 갱신 (매주 토요일 추첨 후)

1. 최신 회차를 추가한 CSV를 **`new_회차.csv`** 이름으로 저장합니다. (예: 1251회 추첨 후 → `new_1251.csv`, 형식: `round,draw date,num1,...,num6`)
2. GitHub 저장소의 `data` 폴더에서 **Add file → Upload files**로 올리고 커밋합니다.
3. 끝. 앱이 날짜로 이번 회차를 계산해 `new_1252 → new_1251 → new_1250 …` 순서로 찾아, 가장 최신 파일을 자동으로 불러옵니다.

- 이전 파일(`new_1250.csv` 등)은 지워도 되고 기록으로 남겨 둬도 됩니다.
- 앱 안의 내장 데이터까지 바꾸려면 `src` 폴더에서 `python3 build.py --data`를 실행하고 `index.html`을 커밋합니다(선택 사항).
- 사용자는 앱 하단 **당첨번호 데이터**에서 CSV를 직접 올릴 수도 있습니다(동행복권 원본 CP949 지원).

## 🏛️ 정밀 엔진 (별관 · `precision/`)

주소: https://kkbhong71.github.io/weekly-seollem/precision/ (본관 상단 **🏛️ 정밀 엔진** 버튼)

본관의 15가지 렌즈와 따로 동작하는 독립 페이지예요. LOTTO INTEGRATED v2.0(Python)의 **v1.2 원본 조합 점수 방식**을 그대로 이식했고, **인기도 회피는 쓰지 않습니다.**

- 8종 번호 점수(빈도·최근·갭·쌍·모멘텀·구간·마르코프·Lift) → 12종 필터 → 4종 생성(가중치·구간 밸런스·동반출현·다중 클러스터) → 커버리지·클러스터 다양성 선택
- Python 원본과 교차검증: 최종 점수 최대 오차 1.4×10⁻¹⁷, 필터 판정 200,300건 불일치 0건
- 시드 고정(기본 42): 같은 데이터·같은 시드면 같은 번호
- 랜덤 대조군 백테스트(모델 / 순수 랜덤 / 필터 랜덤, 회차별 짝지은 비교 + 이항검정), 다중 윈도우, 예측 기록·자동 채점
- 기록은 본관과 다른 키(`seollem.precision.v1`)에 저장돼 섞이지 않아요
- 데이터: 본관과 같은 `data/new_XXXX.csv`를 자동으로 읽음 → 매주 업로드 한 번으로 두 페이지가 함께 갱신

```
precision/index.html        완성본 (배포 파일)
precision/src/engine_v2.js  정밀 엔진 (순수 계산)
precision/src/page.html     화면 템플릿
precision/src/build.py      빌드: python3 build.py (precision/src 폴더에서)
```
